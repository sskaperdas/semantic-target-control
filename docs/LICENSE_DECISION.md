# License decision

A public software repository requires an explicit license.

Two conventional options are already represented by templates under
`.release/license-templates/`:

- **Apache-2.0** — includes an express patent grant and is often suitable for
  research software intended for broad reuse.
- **MIT** — shorter and permissive.

The final choice should be agreed by both authors and, where applicable, the
institution. Dataset terms, paper copyright and third-party dependencies remain
separate from the software license.
