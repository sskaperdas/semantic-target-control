# Security policy

Do not disclose credentials, private dataset links, access tokens, licensed raw data, or other sensitive material in public issues.

Use GitHub private vulnerability reporting for this repository when it is enabled:

https://github.com/sskaperdas/semantic-target-control/security/advisories/new

Before every public release, run the bundled repository audit and review `results/provenance/release/SECURITY_SCAN_REPORT.md`.
